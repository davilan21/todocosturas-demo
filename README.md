# Todocosturas · Facturas

Prototipo frontend (solo demo, datos ficticios) de un sistema que lee facturas
de proveedores desde el correo, las deja listas para revisar y las envía a Siigo.

**Demo:** https://davilan21.github.io/todocosturas-demo/

```bash
npm install
npm run dev
```

Ver `AGENTS.md` para estructura y convenciones.
